TRAINING TOOL
URL after upload: https://task-b.com/training-tool/
Prototype password in this package: TaskB2026!

The password is stored only as a SHA-256 hash in training-tool/login.js. To change it:
1. Calculate a SHA-256 hash for the new password.
2. Replace the value of PASSWORD_SHA256 in training-tool/login.js.

Example on Linux/macOS:
  printf 'NEW_PASSWORD' | sha256sum

Important: this is intentionally only a casual-access deterrent on a static GitHub Pages site. It is not secure authentication. Do not use it to protect paid/private material without server-side authentication.
